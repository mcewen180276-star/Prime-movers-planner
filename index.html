Install & use

Upload every file in this ZIP to the root of a GitHub Pages repository. Open the published HTTPS address in Chrome or Edge, then use the browser menu to install the app or add it to the home screen if offered. Some in-app browsers (including messaging apps) do not show installation controls: open the link in your main browser instead.

Offline use is available after the app is loaded on a compatible browser. External demo links still require internet access.

Teaching guidance

Choose exercises based on individual ability, mobility, confidence and health needs rather than age alone. Allow longer transitions and stable supports when needed; avoid exercises that cause pain, dizziness or unusual breathlessness. Participants with medical concerns should follow appropriate professional advice.
