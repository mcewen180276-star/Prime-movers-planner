PRIME MOVERS CIRCUIT PLANNER V1

UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html, app.js, sw.js, manifest.webmanifest, and icon.svg to the root of your GitHub Pages repository.
3. Enable GitHub Pages in Settings > Pages, using the main branch / root.
4. Open your published HTTPS URL in Chrome/Edge.
5. In the browser menu choose Install app or Add to Home Screen (when supported).

FEATURES
- Automatic duration fitting or manual class timings
- Stations, rounds, warm-up, cool-down, rest, changeover and round breaks
- Mixed-ability options and equipment-aware exercise selection
- 500+ searchable exercise entries/variations, with curated coaching notes
- Exercise-specific YouTube search fallback (not guaranteed verified videos)
- Add/edit custom exercises with direct HTTPS demo links
- Edit, reorder, duplicate, delete and add stations
- Large instructor timer with optional audio and spoken next-phase cues
- Print class and station cards
- Save/load classes, JSON backup/import, offline caching

LIMITATIONS
- All data is saved only to this browser/device. Export backups regularly.
- Automatic duration fitting is approximate; the exact calculated total is shown in the class plan.
- Demo search links are search results, not individually verified video demonstrations.
- Browser audio and fullscreen behaviour depend on device/browser support.
- For install controls, open the GitHub Pages link in a regular browser rather than inside Messenger.
